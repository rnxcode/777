# 🎰 JackpotWatcher 777 — Ловец Семёрок

Когда чат вибрирует от очередного спина, лишь один герой не моргает — ваш юзербот.  
Он фиксирует **🎰 7 7 7**, считает победы, хранит поражения и открывает путь тем, кто превращает Telegram Stars в настоящие игровые ставки.

---

## ✨ Возможности

**• Мгновенное определение результатов казино-эмоджи**  
**• Обнаружение джекпота 777**  
**• Подробная статистика побед и поражений**  
**• Идеальная совместимость с чатами, где сообщения стоят звезды**  
**• Работает как фундамент мини-казино в Telegram**

---

## 🚀 Установка

```bash
git clone https://github.com/byebyedev/777
cd 777
pip install -r requirements.txt
python main.py
```


## 🧠 Принцип работы

1. Юзербот заходит под вашим аккаунтом.  
2. Следит за сообщениями в выбранных чатах.  
3. Находит слот-эмоджи.  
4. Извлекает результат спина.  
5. Фиксирует данные в статистике.  
6. Сообщает вам события, включая легендарный **джекпот 777**.
